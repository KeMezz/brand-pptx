# デザインシステム — `theme.json` の設計指針

このスキルのデザインは、すべて `theme.json` のトークンに集約されている。
ここでは各トークンの役割と、ブランドに合わせて値を決めるときの考え方をまとめる。

## カラーパレット

`theme.json` の `colors` は **役割（ロール）ベース** で定義する。色そのものではなく「何に使う色か」で名前を付けることで、ブランドを差し替えても生成コードを変えずに済む。

| トークン | 役割 | 既定値（中立スターター） |
|----------|------|--------------------------|
| `primary` | ブランドメインカラー。表紙パネル・セクション/エンディング背景 | `27314A` |
| `primaryLight` | プライマリの明るい派生。補助的な面・装飾 | `49546E` |
| `accent` | 強調色。KPI 数値・進捗バー・ステップ円・アクセント | `5B6CFF` |
| `accentLight` | アクセントの明るい派生。矢印・サブ要素 | `C7CDFF` |
| `bg` | カード・トラックの背景（非常に薄い面） | `F4F5FA` |
| `dark` | 本文・タイトルの主テキスト | `131722` |
| `gray` | 説明テキスト・キャプション | `5A6473` |
| `lightGray` | 補助テキスト・プレースホルダー | `9AA1B2` |
| `border` | 罫線・区切り線 | `E2E5EE` |
| `white` | 反転テキスト・背景 | `FFFFFF` |

> **`#` を付けない**: 色は `"27314A"` のように 6 桁 hex で書く。`#` 付き・8 桁（不透明度込み）は PptxGenJS でファイルを壊す。

> 既定テンプレート（`assets/template.pptx`）の表紙パネル・セクション背景・アクセント装飾は、これらの色から `tools/build_template.py` が描く。色を変えて再実行すると既定テンプレートの配色も変わる。

### カラールール（必須）

- **パレット厳守** — `theme.json` のトークンのみを使う。生成コードに色を直書きしない（`C["accent"]` のように参照する）。
- **明度・彩度を勝手にいじらない** — 必要なら `theme.json` 側にトークンを追加する。唯一の例外は透過（`transparency` / `opacity`）。
- **グラデーション禁止** — ソリッドカラーのみ。
- **アニメーション・トランジション禁止** — すべてのスライドは静的に。

### ブランドカラーの決め方（差し替え時）

1. ブランドのメインカラーを `primary` に。
2. 数値や進捗など「目を引かせたい一点」に使う色を `accent` に（`primary` と同じでも可）。
3. `bg` は `primary` をごく薄くしたトーン、または中立のごく薄いグレーに。
4. `dark` / `gray` はテキスト用にコントラストを確保（背景比 4.5:1 以上が目安）。

## フォント

| トークン | 役割 | 既定値 |
|----------|------|--------|
| `heading` / `headingCJK` | 見出し・タイトル（欧文 / 和文） | `Arial` / `Noto Sans JP` |
| `body` / `bodyCJK` | 本文・説明（欧文 / 和文） | `Arial` / `Noto Sans JP` |

- クロスプラットフォーム互換性のため、システムにあるフォントを優先する。
- **本文・キャプションはボールド禁止**。ボールドは見出しとタイトルにのみ使う。

## タイポスケール

`theme.json` の `typeScale`（pt）。

| トークン | 用途 | 既定値 |
|----------|------|--------|
| `coverTitle` | カバーの大タイトル | 48 |
| `coverSubtitle` | サブタイトル・日付 | 20 |
| `sectionTitle` | セクション/クロージングのタイトル | 40 |
| `title` | コンテンツのページタイトル | 28 |
| `subtitle` | 副見出し | 20 |
| `body` | 本文・説明 | 16 |
| `caption` | 注釈・出典・ラベル | 12 |
| `kpiValue` | KPI などのキー数値 | 44 |

**サイズのコントラストを効かせる**: タイトル（28pt+）と本文（14〜16pt）の差をはっきり付ける。

## スタイルレシピ（角丸・余白のトーン）

同じ配色でも、角丸と余白の取り方でトーンが変わる。`theme.json` の `style.cornerRadiusIn` で調整する。

| スタイル | 角丸 (in) | 余白 | 向いている用途 |
|----------|-----------|------|----------------|
| Sharp & Compact | 0 〜 0.05 | タイト | データ密度の高いレポート |
| **Soft & Balanced** | 0.08 〜 0.12 | 標準 | **汎用（既定）。プロフェッショナルかつ親しみやすい** |
| Rounded & Spacious | 0.15 〜 0.25 | ゆとり | 外部向け提案・マーケティング |
| Pill & Airy | 0.3 〜 0.5 | 広い | ブランド紹介・イベント |

## スペーシング（16:9 = 13.333"×7.5" 基準）

| 用途 | 推奨値 (in) |
|------|-------------|
| ページ安全マージン | 0.4 〜 0.6 |
| アイコンとテキストの間隔 | 0.08 〜 0.15 |
| リスト項目の間隔 | 0.15 〜 0.25 |
| カード内パディング | 0.2 〜 0.4 |
| 主要ブロック間隔 | 0.5 〜 0.8 |

**間隔は混ぜない**: 0.3" か 0.5" など一定値を決めて全体で揃える。

## フッター・機密注記について

- **自社テンプレートの場合**: フッターや機密表記がテンプレートのレイアウトに組み込まれている場合は、対応するレイアウトでクロージングするだけで表示される。自前で重ね描きしない（二重になる）。
- **同梱の既定テンプレートの場合**: そうした表記は無い。必要なら `theme.json` の色を使って明示的に描画する。
