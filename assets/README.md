# assets/

自社ブランドの資産を置く場所です（このリポジトリには特定企業の資産は含まれていません）。

- **自社テンプレート PPTX** — 例: `your-template.pptx`。`theme.json` の `template.path` で指定します。
  レイアウト index は `python3 tools/inspect_template.py assets/your-template.pptx` で確認できます。
- **ロゴ** — 例: `logo-dark.png`（明るい背景用）/ `logo-white.png`（濃い背景用）。`theme.json` の `logo` で指定します。

> ここに置く資産は利用者が自身の権利の範囲で用意・管理してください。
